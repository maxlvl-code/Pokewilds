# PokéWilds GBA

Experimental GBA demake/reimplementation of the PokéWilds gameplay loop, targeting Pokémon Emerald/pokeemerald-expansion as the eventual runtime base.

## Prototype goal

The first milestone proves the difficult systems before content production: deterministic seeded terrain, chunk streaming, biome selection, persistent world edits, and a GBA-oriented save representation.

This repository does not distribute a Pokémon Emerald ROM. Final releases should be distributed as patches against a legally obtained compatible base ROM.
